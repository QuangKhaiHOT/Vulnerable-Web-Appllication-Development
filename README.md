# Vulnerable Web Application Development (VWAD)

Ứng dụng web được xây dựng với các lỗ hổng bảo mật cố ý, phục vụ mục đích nghiên cứu và thực hành Pentest.

## 📌 Giới thiệu
Dự án tạo ra một môi trường Lab an toàn để mô phỏng các kỹ thuật tấn công và học cách viết code bảo mật (Secure Coding) dựa trên thực tế.

## ✅ Những gì đã làm được
* **Xây dựng nền tảng:** Thiết lập khung ứng dụng web cơ bản phục vụ thử nghiệm.
* **Tích hợp lỗ hổng:** Triển khai thành công các lỗi phổ biến theo chuẩn **OWASP Top 10**:
    * **Injection:** SQL Injection và Command Injection.
    * **XSS:** Các kịch bản chèn mã độc JavaScript (Reflected/Stored).
    * **Access Control:** Lỗi IDOR và bypass xác thực người dùng.
    * **Path Traversal:** Khai thác lỗ hổng truy cập tập tin và thư mục trái phép.
